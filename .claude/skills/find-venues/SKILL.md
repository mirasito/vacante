# Ссылки заведений

Ты помогаешь сайту вакансий vacante.kz. У многих вакансий известно заведение («DINO FEST», «Magnum Go»).
Сайт и посты в Telegram-каналах показывают аватар заведения и ссылки на него. Твоя задача: найти для каждого
заведения из очереди его Instagram, сайт и Telegram-канал. Аватар скачает workflow: с сайта заведения его значок,
из Telegram-канала аватар через API бота, из Instagram только через официальный API. Тебе картинки искать
не нужно, но чем больше ссылок найдёшь, тем больше заведений получат аватар.

Не делай коммитов, веток и PR, не меняй файлы репозитория. Твой единственный результат: запуск `venues.yml`.
Не открывай страницы instagram.com и не пытайся их скачать: Instagram запрещает автоматический сбор.
Достаточно ссылки из карточки 2ГИС или из результатов поиска.

## 1. Прочитать очередь

```bash
git fetch -q origin +refs/heads/data:refs/remotes/origin/data
git show origin/data:venues_queue.json
```

Если файла нет или `venues` пустой, напиши «Очередь заведений пуста» и закончи.

У каждого заведения: `key` (его нужно вернуть как есть), `name`, `city_name`, сколько у него вакансий,
должность, адрес и начало текста последней вакансии. По тексту понятно, что это за место: кафе, магазин, склад.

Возьми первые 20 заведений по порядку. Остальные возьмёт следующий запуск. В очереди бывают и заведения,
которые разбирали раньше, когда искали только Instagram: найди для них все ссылки заново, как для новых.

## 2. Решить, искать ли

**skip**: это не название конкретного заведения, искать нечего:
- общее слово или описание: «Банный комплекс», «Бизнес-центр», «Кафе», «Ресторан паназиатской кухни»;
- должность, фраза из объявления, капс-призыв: «Требуется», «Настоящую пекарню»;
- имя человека или ИП по фамилии: «Асхат», «ИП Исмаилова»;
- набор букв: «Vvcg».

Остальное ищи.

## 3. Найти ссылки

1. **2ГИС.** WebSearch: `<name> <city_name> 2ГИС`. Найди карточку `2gis.kz/<город>/firm/<id>`, у которой
   название совпадает с заведением, а город с `city_name`. Открой её WebFetch с вопросом: «Название, рубрика,
   адрес и все ссылки в контактах: Instagram, Telegram, сайт, точно как на странице». В карточке 2ГИС они
   указаны в контактах. Сайтом считается и страница вроде taplink.cc/<заведение>; WhatsApp, VK и сама 2ГИС не нужны.
2. **Поиск по Instagram.** Если в 2ГИС карточки или Instagram нет: WebSearch `<name> <city_name> instagram`
   с `allowed_domains: ["instagram.com"]`. Заголовок результата выглядит как
   «Dino Fest Almaty (@dino_fest_almaty) • Instagram photos and videos».
3. **Сайт.** У сетей и крупных заведений (Magnum, SMALL, Coffee Boom) обычно есть сайт: если его нет в 2ГИС,
   один WebSearch `<name> <city_name> официальный сайт`.

Принимай ссылку, только если уверен, что это то самое заведение:
- название аккаунта или имя в заголовке совпадает с названием заведения (с точностью до регистра, пробелов
  и транслитерации: «Пельмень» и «pelmen» совпадают);
- город совпадает, или это сеть, которая работает в этом городе (для сетей бери аккаунт этого города, если он
  есть, иначе общий казахстанский: `magnum.kz`, а не российский или турецкий);
- род занятий подходит к вакансии: у кофейни аккаунт кофейни, а не одноимённого салона красоты.

Сомневаешься: не передавай эту ссылку. Неверная ссылка хуже, чем никакой: аватар чужого заведения увидят
тысячи людей. Если не нашлось ни одной ссылки: **none**.

Не трать на одно заведение больше трёх поисков.

## 4. Передать находки

Собери JSON-массив, по объекту на каждое заведение, которое ты разобрал:

```json
[
  {"key": "almaty:dino fest", "status": "found", "instagram": "dino_fest_almaty",
   "source": "https://2gis.kz/almaty/firm/70000001110093666"},
  {"key": "almaty:small", "status": "found", "instagram": "small.kz", "website": "https://small.kz",
   "source": "https://2gis.kz/almaty/firm/..."},
  {"key": "astana:coffee boom", "status": "found", "telegram": "coffeeboom_kz", "source": "..."},
  {"key": "almaty:qaimaq bakery", "status": "none"},
  {"key": "astana:банный комплекс", "status": "skip"}
]
```

- `status`: `found` (найдена хотя бы одна ссылка), `none` (заведение настоящее, но ссылок не нашлось) или `skip`.
- `instagram`, `telegram`, `website`: только для `found`, только найденные. Instagram и Telegram: ник без `@`
  или ссылка; сайт: адрес. Telegram только публичный канал или группа заведения (`t.me/<ник>`), не личный
  аккаунт и не приглашение `t.me/+...`.
- `source`: где нашёл (ссылка на карточку 2ГИС или на профиль), только для `found`.
- `name` можно не передавать: оно уже есть в очереди.

Сохрани массив в `/tmp/venues.json`, проверь, что JSON валиден, запусти workflow одним вызовом и прочитай итог
по каждому заведению из аннотаций (логи скачать нельзя, а аннотации можно):

```bash
python3 -c 'import json,sys; json.load(open(sys.argv[1]))' /tmp/venues.json
since=$(date -u +%Y-%m-%dT%H:%M:%SZ)
gh workflow run venues.yml --repo mirasito/vacante --ref main -f results="$(cat /tmp/venues.json)"
sleep 10
run=$(gh run list --repo mirasito/vacante --workflow venues.yml --limit 5 --json databaseId,createdAt \
  --jq "[.[] | select(.createdAt >= \"$since\")] | last | .databaseId")
gh run watch "$run" --repo mirasito/vacante --exit-status >/dev/null || true
job=$(gh api "repos/mirasito/vacante/actions/runs/$run/jobs" --jq '.jobs[0].id')
gh api "repos/mirasito/vacante/check-runs/$job/annotations" \
  --jq '.[] | select(.title == "Заведения" or .title == "Аватары") | "\(.annotation_level) \(.title):\n\(.message)"'
```

Если `gh` недоступен, но есть GitHub MCP: `actions_run_trigger` (method `run_workflow`, owner `mirasito`,
repo `vacante`, workflow_id `venues.yml`, ref `main`, inputs `{"results": "<JSON-массив строкой>"}`).

Аннотация «Заведения»: по строке на заведение, `ключ: found instagram=... website=...`, `ключ: none`
или `ключ: skip`. Ошибки приходят отдельной аннотацией с тем же названием и уровнем `failure`: `error: ...`
у заведения значит, что ты передал неверное поле. Исправь и отправь заново только эти заведения.

Аннотация «Аватары»: `аватар скачан (website)` или `аватара нет: ...` (на сайте нет квадратного значка,
у канала нет аватара: это нормально). Строка `instagram: error: ...` или `telegram: error: ...` уровня
`failure` значит, что не подошёл токен Instagram или бота: ссылки сохранились, а аватары из этого источника
не скачались. Сообщи об этом.

В конце напиши одну строку: у скольких заведений нашлись ссылки, у скольких нет, сколько пропущено и сколько получили аватар.
